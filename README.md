# 30 Days of Low Level Design (LLD) Challenge

A 30-day journey to build a strong foundation in Low Level Design — covering OOPs fundamentals, SOLID principles, design patterns, and real-world LLD problems commonly asked in interviews.

## 🎯 Goal

To become confident in designing clean, scalable, and maintainable object-oriented systems by practicing daily — theory + hands-on code, every single day for 30 days.

## 📅 Progress

| Day | Topic | Status |
|-----|-------|--------|
| 1 | OOPs revision (Encapsulation, Abstraction, Inheritance, Polymorphism) + SOLID (SRP, OCP, LSP) | ✅ Done |
| 2 | Interface Segregation & Dependency Inversion | 🔲 Upcoming |
| 3 | UML basics & class diagrams | 🔲 Upcoming |
| 4-30 | Design patterns + real-world LLD problems (Parking Lot, Elevator System, Library Management, etc.) | 🔲 Upcoming |
